# Реестр функций

Каждая строка — отдельное действие пользователя или серверная операция, найденная в коде. ID стабильны: сообщайте о проблемах по ним.

**Готовность** — по коду и наличию автотестов, не по ручному прогону:

- **Подтверждено тестами** — есть серверные или целевые тесты сценария (PGlite). UI всё равно нужно пройти вручную.
- **Реализовано, требует ручной проверки** — UI + серверная запись есть, полного автотеста сценария нет.
- **Частично реализовано** — заглушка, обрубленный поток или сервис без UI.
- **Не реализовано** — заявлено архитектурой/остатками схемы, экрана нет.
- **Не удалось определить** — поведения из кода недостаточно.

Колонка **Сохранение:** «чтение» / «запись в …» / «опасно».

Автотесты лежат в `tests/`. Имена файлов указаны кратко.
