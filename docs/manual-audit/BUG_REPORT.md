## BUG-004 — Ученик «прыгает» на Дмитрия при навигации в Аудитории

- **Серьёзность:** P1
- **Статус:** исправлен
- **Сценарий:** MT-090 / MT-091, повторно при смене кабинета
- **Ожидание:** выбранный ученик и роль сессии не меняются от перехода по страницам того же кабинета. После смены кабинета сессия соответствует URL.
- **Факт (до фикса):** эффект demo-boot зависел от `pathname`, повторно вызывал `apiDemoLogin` и подставлял `sch_s01` (Дмитрий Алексеев). Позже при Кафедра → Аудитория UI показывал Дмитрия, а `/api/auth/me` оставался преподавателем Еленой; оценка занятия отвечала «Недостаточно прав».
- **Причина:** гонка: отменённый boot всё равно завершал `apiDemoLogin` и перезаписывал cookie после уже завершённого нового boot. UI брал `filterStudentId`, если `auth.role !== "student"`.
- **Исправление:**
  - `demoSessionBootKey` — один ключ на кабинет, не на каждый URL;
  - проверки `cancelled` до demo-login;
  - очередь `createSerialAsyncQueue`, чтобы поздний login не перебивал последний кабинет;
  - `setReady(false)` при смене кабинета, пока сессия не совпадёт с URL.
- **Файлы:** `src/lib/store/demo-session.ts`, `src/lib/store/demo-store.tsx`, `tests/lib/demo-session.test.ts`.
- **Регрессия:** 6 unit-тестов demo-session, включая сериализацию очереди.
- **Повторная проверка:** Кафедра (Елена / teacher) → Аудитория (Дмитрий / student), повторный `/api/auth/me` через 3 с — student. PASS.

## BUG-007 — «Выйти» в локальном demo сразу логинит снова

- **Серьёзность:** P2 локально
- **Статус:** исправлен в коде (этап 2); UI не подтверждён
- **Сценарий:** MT-174
- **Ожидание:** выход на `/login`, сессии нет, автологин не поднимает её сразу.
- **Факт (прогон 1):** logout API сбрасывал cookie, boot сразу вызывал `apiDemoLogin`.
- **Исправление:** флаг `tp.demo.skipAutoLogin` в **sessionStorage** (только вкладка, не production-cookie). Ставится при «Выйти», снимается при успешных `apiLogin` / `apiDemoLogin`. `shouldDefaultDemoLogin` учитывает `skipAutoLogin`.
- **Регрессия:** unit-тесты skip/clear; очередь асинхронных login.
- **UI этап 2:** не подтверждён (локальный HTTP недоступен).

- **Серьёзность:** P3

- **Сценарий:** смена кабинета, пока сессия ещё чужая; MT-012 / чат Кафедры и Аудитории

- **Регрессия:** `tests/lib/chat-poll.test.ts` (4).
