# Прототип: Дирекция / Кафедра

Локальный прототип платформы для онлайн-репетиторского бизнеса.

Два кабинета:

- **Дирекция** — владелец: ученики, преподаватели, группы, расписание, задания, результаты
- **Кафедра** — преподаватель: свои ученики, занятия с посещаемостью, задания и оценки

Без реальной БД и авторизации. Данные в `localStorage` (+ кнопка «Сбросить демо»).

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · npm

## Запуск

```bash
npm install
npm run dev -- -H 0.0.0.0 -p 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Проверки

```bash
npm run lint
npm run build
```

## Маршруты

| URL | Кабинет |
|-----|---------|
| `/` | Выбор кабинета |
| `/direkciya/*` | Дирекция |
| `/kafedra/*` | Кафедра |

Кабинет «Аудитория» в этот прототип не входит.
