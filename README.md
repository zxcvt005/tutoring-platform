# Прототип: Дирекция / Кафедра

Локальный прототип платформы для онлайн-репетиторского бизнеса.

## Кабинеты

- **Дирекция** — владелец: ученики по преподавателям, карточки преподавателей, недельный календарь, результаты ДЗ
- **Кафедра** — преподаватель: день сегодня, своё расписание, темы и домашние задания, посещаемость

Групп нет. Кабинет «Аудитория» не входит в MVP.

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · npm · localStorage (`naemnye.demo.v2`)

## Запуск

```bash
npm install
npm run dev -- -H 0.0.0.0 -p 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

Кнопка «Сбросить демо» восстанавливает seed v2. Старые данные v1 с группами игнорируются.

## Проверки

```bash
npm run lint
npm run build
```
