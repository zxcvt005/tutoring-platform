# Прототип: Дирекция / Кафедра / Аудитория

Локальный прототип платформы для онлайн-репетиторского бизнеса.

## Кабинеты

- **Дирекция** — владелец: ученики по преподавателям, карточки преподавателей, недельный календарь, результаты ДЗ
- **Кафедра** — преподаватель: день сегодня, своё расписание, темы и домашние задания, посещаемость, проверка работ
- **Аудитория** — ученик: главная, расписание, обучение со сдачей ДЗ, результаты, профиль

Данные общие (один DemoStore / localStorage). Групп нет. Без БД, auth и видеозвонков.

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · npm · localStorage (`naemnye.demo.v4`)

## Запуск

```bash
npm install
npm run dev -- -H 0.0.0.0 -p 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

Кнопка «Сбросить демо» восстанавливает seed v4. Данные v2/v3 мигрируют автоматически (ответ ученика, `currentStudentId`).

## Демо-сценарий ДЗ

1. Кафедра (Анна) — назначения уже в seed; можно назначить новое через тему.
2. Аудитория (Алиса) — «Обучение» → открыть ДЗ → отправить ответ.
3. Кафедра → «Результаты» → проверить (балл + комментарий).
4. Аудитория → «Результаты» — балл и комментарий.
