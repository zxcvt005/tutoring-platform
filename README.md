# Прототип: Дирекция / Кафедра / Аудитория

Локальный прототип платформы для онлайн-репетиторского бизнеса.

**Один Next.js-приложение, один порт (`43127`), три кабинета.** Hot reload — штатный `next dev`.

## Кабинеты

| Кабинет | Роль | URL |
|---------|------|-----|
| **Дирекция** | владелец | http://127.0.0.1:43127/direkciya |
| **Кафедра** | преподаватель | http://127.0.0.1:43127/kafedra |
| **Аудитория** | ученик | http://127.0.0.1:43127/auditoria |

Стартовая страница: http://127.0.0.1:43127/

Данные общие (один DemoStore / localStorage v4). Без БД, auth и видеозвонков.

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · npm · localStorage (`naemnye.demo.v4`)

## На вашем Windows

1. Установите [Node.js LTS](https://nodejs.org/) (18+, лучше 20 или 22).
2. Клонируйте репозиторий и перейдите на ветку с кабинетами (см. актуальный commit в заметках команды). Пример:

   ```powershell
   git clone <url-репозитория>
   cd <папка-репо>
   git checkout cursor/local-windows-dev-8154
   ```

3. Запустите **двойным щелчком** `start.bat`  
   или в PowerShell из корня репо:

   ```powershell
   .\start.ps1
   ```

   Скрипт при необходимости выполнит `npm install` и поднимет `npm run dev:local` на порту **43127**.

4. Откройте в браузере адреса из таблицы выше. Правки в коде подхватываются hot reload без перезапуска.

Остановка: `Ctrl+C` в окне терминала.

Подробнее: документ `local-windows-setup` в Project Context (`docs/`).

## Запуск вручную (любая ОС)

```bash
npm install
npm run dev:local
```

Эквивалент: `next dev -H 0.0.0.0 -p 43127`.

## Демо-сценарий ДЗ

1. Кафедра (Анна) — назначения уже в seed; можно назначить новое через тему.
2. Аудитория (Алиса) — «Обучение» → открыть ДЗ → отправить ответ.
3. Кафедра → «Результаты» → проверить (балл + комментарий).
4. Аудитория → «Результаты» — балл и комментарий.

Кнопка «Сбросить демо» восстанавливает seed v4. Данные v2/v3 мигрируют автоматически.
